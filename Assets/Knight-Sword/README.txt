# Knight Sword – Stylized 3D Asset

A stylized medieval sword designed for fantasy and RPG games.

## Features:
- Formats: FBX / OBJ / GLB
- Stylized PBR textures (Base Color, Metallic, Roughness, Normal)
- Game-ready and optimized for Unity, Unreal, Godot, and others
- Clean UVs and low-poly topology

## How to Use:
1. Import the FBX/OBJ/GLB file into your game engine.
2. Apply the provided PBR texture maps to the material.
3. Adjust material settings if necessary to match your lighting setup.
