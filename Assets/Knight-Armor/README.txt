# Knight Armor Set – Stylized 3D Asset

A full medieval knight armor set including helmet, chestplate, gauntlets, and greaves.

## Features:
- Formats: FBX / OBJ / GLB
- PBR texture maps included
- Stylized design, static model (not rigged)
- Optimized for games and stylized art styles

## How to Use:
1. Import the model into Unity or Unreal Engine.
2. Apply the included textures to the material.
3. Use as character gear or environmental prop.
*Note: This model is not rigged for animation, but can be rigged manually if needed.*
