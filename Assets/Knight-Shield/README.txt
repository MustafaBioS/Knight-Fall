# Knight Shield – Stylized 3D Asset

A defensive shield with stylized medieval design, perfect for fantasy settings.

## Features:
- Formats: FBX / OBJ / GLB
- Includes PBR texture maps (Base Color, Metallic, Roughness, Normal)
- Optimized for real-time rendering
- Hand-painted style

## How to Use:
1. Import the model file into Unity, Unreal, or your preferred engine.
2. Create a material and assign the textures accordingly.
3. Use it as equipment or decorative element in your scene.
