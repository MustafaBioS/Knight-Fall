**<h1>Knight Fall</h1>**
Knight Fall is my first 3D Game, it's a game where you play as a knight that can do sieges.
---
**<h1>Keybinds</h1>**
> W -> Move Forward<br>
> A -> Move Left<br>
> S -> Move Backward<br>
> D -> Move Right<br>
> Space -> Jump<br>
> E -> Interact<br>
> LMB -> Attack<br>
> I -> Show Inventory<br>
> R -> Switch Weapon<br>
> ESC -> Exit
